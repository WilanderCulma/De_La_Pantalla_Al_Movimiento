# Lúdica y Territorio: De la pantalla al movimiento

Ambiente de aprendizaje web (sitio estático, sin dependencias) generado a partir del documento *Trayecto de actividades* de la Unidad 2.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube `index.html`, `README.md` y `.nojekyll`.
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. En uno o dos minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

El avance de cada estudiante se guarda solo en su navegador (localStorage).

Los botones marcados «enlace pendiente» (inscripción, audio, entrada, salida y muro) se activan cuando se agregan sus enlaces.

La carpeta `recursos/infografias/` contiene las cuatro infografías; súbela junto con `index.html`.
Para la Estación 3, la carpeta `recursos/estacion3/` contiene la cartilla y la bitácora imprimible (PDF); súbela también.
